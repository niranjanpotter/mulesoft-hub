MuleSoft for Flow: Integration — Capabilities, Setup & When to Use It

Understand what MuleSoft for Flow: Integration lets you do inside Salesforce Flow Builder—using third-party connectors and Anypoint APIs cleanly without custom Apex.

⚡ Quick Answer

MuleSoft for Flow: Integration lets you call third-party connectors (Slack, Jira, Workday, NetSuite, Snowflake, Google Workspace) and governed Anypoint Exchange APIs directly as native Flow Actions inside Salesforce Flow Builder—eliminating boilerplate Apex HTTP callouts and Named Credential plumbing.

What MuleSoft for Flow: Integration Lets You Do

  • Use Third-Party Connectors Directly in Flow: Drag external SaaS actions (create a Jira ticket, update a NetSuite invoice, post to a Slack channel, or sync Snowflake rows) directly onto your Record-Triggered or Screen Flow canvas.
  • Invoke Governed Anypoint Exchange APIs: Surface REST APIs built by your MuleSoft team in Anypoint Exchange as strongly-typed invocable actions in Flow Builder via API Catalog.
  • Power Agentforce Actions: Wrap external Flow actions as Agentforce Topics/Actions so AI agents can trigger governed backend updates safely.
  • Eliminate Custom Apex Callouts: Admins can configure OAuth/API credentials once and reuse them across Flows without writing `@InvocableMethod` Apex code.

Quick Setup Checklist in Salesforce

  1. Enable MuleSoft for Flow: Integration in Salesforce Setup under Automation / MuleSoft.
  2. Connect your Anypoint Organization (or enable native third-party connectors) and assign the MuleSoft for Flow permission set to Flow Builders.
  3. In Flow Builder, add an Action element, filter by MuleSoft Connectors or Anypoint APIs, map input variables, and test in Flow Debug.
