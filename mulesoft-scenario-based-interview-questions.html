Architecture Deep-Dive Q&A

Q1 [PRODUCTION ARCHITECTURE] ⏱️ 3 min read

Scenario 1: Downstream SAP system experiences a 5-second latency spike. How do you prevent thread starvation in MuleSoft?

🎯 HOW TO ANSWER (SENIOR ARCHITECT SCRIPT)

When SAP slows down, HTTP Listener worker threads (CPU_LITE) become exhausted waiting on BLOCKING_IO threads. We mitigate this by: 1) Configuring aggressive response timeouts on the SAP connector (e.g., 3000ms); 2) Implementing a Circuit Breaker policy in API Manager to fail fast with HTTP 503; 3) Offloading synchronous calls to asynchronous queues using Anypoint MQ.

Q2 [PRODUCTION ARCHITECTURE] ⏱️ 3 min read

Scenario 2: Salesforce write succeeds but Anypoint MQ publish fails (Dual-write failure). How do you resolve consistency?

🎯 HOW TO ANSWER (SENIOR ARCHITECT SCRIPT)

Without heavy distributed XA transactions, we implement the Outbox Pattern or Local Compensating Transactions: wrap the operations in a Try scope with on-error-propagate. If Anypoint MQ fails, execute a compensating Salesforce delete or set Status='PENDING_SYNC', triggering a scheduled retry flow.
