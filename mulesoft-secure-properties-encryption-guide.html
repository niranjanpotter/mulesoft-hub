<?xml version="1.0" encoding="UTF-8"?>
<mule xmlns="http://www.mulesoft.org/schema/mule/core"
      xmlns:secure-properties="http://www.mulesoft.org/schema/mule/secure-properties"
      xmlns:db="http://www.mulesoft.org/schema/mule/db">
  <secure-properties:config name="Secure_Properties_Config"
    file="config-${mule.env}-secure.yaml" key="${mule.key}">
    <secure-properties:encrypt algorithm="AES" mode="GCM"/>
  </secure-properties:config>

  <db:config name="Postgres_Config">
    <db:generic-connection url="${db.url}" user="${db.user}" password="${secure::db.password}"/>
  </db:config>
</mule>

Anypoint Platform / CloudHub 2.0 / Gateway Click-Path

  1. Confirm `mule-artifact.json` declares `"secureProperties": ["mule.key"]` BEFORE deploying so CloudHub never exposes the key in plain text in Runtime Manager.
  2. Pass `mule.key` via CI/CD secrets (`mvn mule:deploy -Dmule.key=${{ secrets.PROD_KEY }}`).

Architecture Deep-Dive Q&A

Q1 [PRODUCTION ARCHITECTURE] ⏱️ 3 min read

What is the difference between AES-CBC and AES-GCM in MuleSoft Secure Properties?

🎯 HOW TO ANSWER (SENIOR ARCHITECT SCRIPT)

AES-CBC is a legacy cipher mode that requires padding and is susceptible to padding oracle attacks if not paired with HMAC authentication. AES-GCM (Galois/Counter Mode) provides authenticated encryption with associated data (AEAD), ensuring both confidentiality and data integrity with hardware acceleration.

💻 CODE / ARCHITECTURE CONFIGURATION
java -cp secure-properties-tool.jar com.mulesoft.tools.SecurePropertiesTool \
  string encrypt AES GCM mySecretKey "db_password123"
Q2 [PRODUCTION ARCHITECTURE] ⏱️ 3 min read

How do you reference secure properties dynamically inside DataWeave 2.0 transformations?

🎯 HOW TO ANSWER (SENIOR ARCHITECT SCRIPT)

Use the MuleSecure::p() function or the standard p('secure::property.name') property placeholder syntax. Ensure the secure property config module is declared in the global XML configuration.
