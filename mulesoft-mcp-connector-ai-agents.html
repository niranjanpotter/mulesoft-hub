Terminal verification command (curl / CLI) 
curl -s -X POST "http://localhost:8081/mcp" -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
Expected JSON / HTTP response 
{ "jsonrpc": "2.0", "id": 1, "result": { "tools": [...] } }

Architecture Deep-Dive Q&A

Q1 [PRODUCTION ARCHITECTURE] ⏱️ 3 min read

What is the Model Context Protocol (MCP) and why is it replacing static API tool calling?

🎯 HOW TO ANSWER (SENIOR ARCHITECT SCRIPT)

MCP is an open standard that standardizes how AI agents discover tools, context, and prompts. Rather than writing brittle custom function calling JSON schemas for every model, MuleSoft MCP bridges translate flow metadata into standardized tool catalogs accessible by any compliant LLM runtime.

Q2 [PRODUCTION ARCHITECTURE] ⏱️ 3 min read

How do you prevent agent hallucination from causing unauthorized data mutations?

🎯 HOW TO ANSWER (SENIOR ARCHITECT SCRIPT)

MuleSoft MCP connector enforces read-only safety modes, rate limits, schema validation policies, and human-in-the-loop approval triggers before executing mutation operations against core ERP backends.
